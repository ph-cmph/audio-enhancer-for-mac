Main modifications in this preview: fixed LP64 parameter copying and uninitialised DSP members; guarded DSP access during UI changes; preallocated/chunked audio buffers; finite sample handling; strict capture/output validation; scoped system-output restoration and crash recovery journal; stopped/disconnected states; session persistence; Unicode preset paths and labels; repaired and expanded tests; independent app identity and quieter blue UI using system fonts. Version 0.2.1 adds virtual-input attenuation correction, synchronised system/playback volume with recoverable virtual-volume restoration, quantitative boost regression tests, and complete equaliser redraw after preset/session changes. Version 0.2.2 adds a passive stereo activity tap, UI-thread spectrum analysis, truthful processing/silence/bypass labels, and an optional audio-driven visualiser that respects macOS Reduce Motion.

Version 0.3.0 renames the product Audio Enhancer for Mac, unifies start/stop with the power icon, removes routine routing controls/status text, keeps actionable error dialogs, and introduces adaptive macOS colours, system typography, rounded cards and geometric slider/power controls. This remains an independent derivative, not an official FxSound release.
